🎥 Biografia do Site

O site Filmes de Terror foi desenvolvido como um trabalho semestral com o objetivo de criar uma experiência interativa inspirada no universo dos filmes de horror.

O projeto reúne reviews, curiosidades e páginas dedicadas a filmes famosos do gênero terror, utilizando uma interface inspirada em câmeras de segurança para criar uma atmosfera mais imersiva.

Cada câmera da página inicial leva o visitante para um filme diferente, permitindo explorar informações, conteúdos e elementos visuais relacionados às obras.

Durante o desenvolvimento foram utilizados HTML, CSS e JavaScript, focando tanto no visual cinematográfico quanto na experiência do usuário.

O site também possui easter eggs escondidos, incentivando os visitantes a explorarem todos os detalhes do projeto.
